# HW1：8086 汇编 Hello World 实验

## 已搭建的环境与运行方法

实验使用 Windows + DOSBox 0.74、MASM 5.10、LINK 3.65 和 FreeDOS DEBUG 2.50。DOSBox 运行 16 位 DOS 程序。工具需自行配置，不随作业上传；挂载和 PATH 设置见仓库根目录 README。

进入 DOSBox 的 `C:\HW1` 后输入 `HELLO` 或 `HELLO2` 运行常规程序，输入 `DEBUG < RAW.DBG` 运行直接写内存实验。编辑 ASM/DBG 时使用 ASCII 纯文本。所有内存操作均发生在 DOSBox 的模拟 DOS 内存中。

## 1. 常规方式：源码 → OBJ → EXE → 运行

在 DOSBox 的 `C:\HW1>` 下输入：

```dos
masm HELLO.ASM,HELLO.OBJ,HELLO.LST,HELLO.CRF;
link HELLO.OBJ,HELLO.EXE,HELLO.MAP;
HELLO
```

末尾分号让 MASM/LINK 使用其余默认选项，不再逐项询问。预期输出：

```text
Hello world!
```

以下编译命令会生成 OBJ、LST、MAP 等辅助文件，它们不在精简提交中保留。

`HELLO.ASM` 是源码；`HELLO.OBJ` 是包含待链接信息的目标文件；`HELLO.EXE` 是可执行程序；`HELLO.LST` 对照源码、段内偏移和机器码；`HELLO.MAP` 记录链接后的段布局。

源码如下：

```asm
.MODEL SMALL
.STACK 100H
.DATA
Hello DB 'Hello world!',0DH,0AH,'$'
.CODE
START:
    MOV AX,@DATA
    MOV DS,AX
    LEA DX,Hello
    MOV AH,09H
    INT 21H
    MOV AX,4C00H
    INT 21H
END START
```

- `.MODEL SMALL`：小内存模型，近代码、近数据；各段的大小受 64 KiB 限制。
- `.STACK 100H`：预留 256 字节栈，由加载器设置 SS:SP。它也供中断保存返回现场；这里显式设置栈。
- `.DATA` 与 `DB`：定义数据段及字节。`0DH` 是回车，`0AH` 是换行；`$` 是 DOS 09H 服务的结束标记，不会显示。
- `.CODE` 与 `START:`：定义代码段、入口标号。
- `MOV AX,@DATA` / `MOV DS,AX`：初始化 DS。不能把立即数直接 MOV 到段寄存器，需借助通用寄存器。
- `LEA DX,Hello`：取得字符串偏移地址，不是读取字符串内容。
- `MOV AH,09H` / `INT 21H`：DOS 根据 AH=09H，从 DS:DX 开始输出直到 `$`。
- `MOV AX,4C00H` / `INT 21H`：AH=4CH 表示结束程序，AL=00H 表示成功返回码。
- `END START`：告诉汇编器入口在哪里，是伪指令，不是 CPU 的退出指令。

### 观察 LEA 与 OFFSET

运行 `HELLO2` 得到相同输出。它仅将 `LEA DX,Hello` 改成 `MOV DX,OFFSET Hello`。

实测反汇编：前者为 `8D 16 02 00`（4 字节），后者为 `BA 02 00`（3 字节）。对本例的固定符号，两者均使 DX=0002H；LEA 还可计算 `[BX+SI+位移]` 等有效地址，而 OFFSET 是汇编/链接时求得的地址常量。

注意重新编译生成的 `HELLO.LST` 中 Hello 的 `_DATA` 段内偏移为 0000H；链接器把数据段分组为 DGROUP 后，本例实际 DS:DX 的 DX 是 0002H。这不是输出多了两个字符。以链接结果和反汇编为准，不要把未链接的列表值直接当作运行地址。

## 2. 直接写内存：不经过 MASM/LINK

在 DOSBox 输入 `DEBUG`，逐行输入以下内容。这里只对 DEBUG 为待运行程序准备的内存操作；段地址使用 CS，避免照抄其他运行环境的固定段值。

```text
e cs:0100 0e 1f ba 00 02 b4 09 cd 21 b8 00 4c cd 21
e cs:0200 48 65 6c 6c 6f 20 77 6f 72 6c 64 21 0d 0a 24
d cs:0200 l 0f
u cs:0100 l 0e
r ip
0100
r
g
q
```

命令输入时不用键入 DEBUG 显示的 `-` 提示符。`r ip` 后的 `0100` 是下一行对 IP 的输入。DEBUG 中这些数字默认按十六进制解释。

同一过程已保存在 `RAW.DBG`；可输入 `DEBUG < RAW.DBG` 自动执行。

机器码对应的操作：

```asm
; CS:0100 开始，共 14 字节
PUSH CS               ; 0E
POP DS                ; 1F，让 DS=CS
MOV DX,0200H          ; BA 00 02
MOV AH,09H            ; B4 09
INT 21H               ; CD 21
MOV AX,4C00H          ; B8 00 4C
INT 21H               ; CD 21
```

第二个 `e` 命令把 15 字节字符串写到 CS:0200H。前两条指令让 DS=CS，因此 DS:DX 精确指向这些数据。`BA 00 02` 的立即数字节是小端序，表示 0200H，不是 0002H。

`e` 写内存、`d` 查看数据、`u` 反汇编、`r` 查看或修改寄存器、`g` 从 CS:IP 开始执行、`q` 退出 DEBUG。执行后同样显示 `Hello world!`，并由 DOS 4CH 服务正常结束。

这就是题目要求的“直接写内存执行机器码”，输出仍然调用 DOS。它与把字符写入 B800H 文本显存是两种不同实验。

## 3. 常用寄存器与地址

8086 的寄存器是 16 位。AX、BX、CX、DX 可拆成两个 8 位部分，例如 AX = AH（高 8 位）+ AL（低 8 位）；AX=4C00H 时 AH=4CH、AL=00H。

- **AX**：常用于计算、返回值和服务参数。本例先中转数据段地址，再用 AH 选择 DOS 服务，AL 给退出码。
- **BX**：常作基址或通用数据寄存器，可用于 `[BX]` 等内存寻址；本例不依赖它。
- **CX**：常作计数，LOOP 和带 REP 的串操作会使用它；本例不依赖它。
- **DX**：通用数据寄存器，也用于端口号、部分乘除法；本例保存字符串偏移。
- **CS:IP**：代码段与下一条指令偏移，共同确定取指地址。IP 不是通用寄存器，通常由跳转/调用改变；DEBUG 可直接修改它。
- **DS**：默认数据段；本例的 DOS 输出服务使用 DS:DX。
- **ES**：附加段，串指令的目标常是 ES:DI；本例不依赖它。
- **SS:SP**：栈段与栈顶偏移。PUSH 使 SP 减 2，POP 使 SP 加 2；调用、返回和中断也会使用栈。
- **BP**：常访问栈中的参数/局部数据，使用 BP 的内存寻址默认取 SS。
- **SI、DI**：源/目标索引；串操作常用 DS:SI、ES:DI。
- **FLAGS**：记录进位 CF、零 ZF、符号 SF、溢出 OF 等状态，也包含方向 DF 和中断允许 IF。通常 MOV/LEA 不修改算术标志；本例不靠条件标志分支。

实模式地址关系：`物理地址 = 段值 × 16 + 偏移`。段值不是完整物理地址，两个不同的“段:偏移”可能指向同一字节。普通 8086 内存操作不能任意使用所有通用寄存器作地址，常用 BX/BP/SI/DI 的规定组合。

### 动手观察寄存器

输入 `DEBUG HELLO.EXE`，先用 `r` 看初始状态，用 `u` 看代码，然后连续执行四次 `t`：

1. 执行 `MOV AX,@DATA`：AX 变成运行时数据组段值。
2. 执行 `MOV DS,AX`：DS 从初始 PSP 段改成数据组段值。
3. 执行 `LEA DX,Hello`：DX=0002H。
4. 执行 `MOV AH,09H`：AH=09H；AX 的低字节仍保留原来的值。

此时 `d ds:dx l 0f` 应显示 `Hello world!..$` 的数据；`g` 输出文字并退出程序，`q` 回到 DOS。不要继续假定 INT 21H 后所有寄存器和标志都保持不变。
