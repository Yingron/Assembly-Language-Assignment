# 作业 5：递归调用

从键盘输入 1～3 个十进制数字，数值须在 1～100，输出按题目定义编号的 F(n)：F(0)=0、F(1)=1、F(n)=F(n−1)+F(n−2)。例如输入 `10` 得到 `F(n) = 55`，输入 `100` 得到 `F(n) = 354224848179261915075`。

## 运行

在 DOSBox 中按仓库首页说明挂载目录，切到 `C:\HW5`，运行 `FIB`。如需重编译：

```dos
masm FIB.ASM;
link FIB.OBJ;
```

C 版在 Windows 的 Cygwin 环境运行 `./FIB_C.exe`。重编译和查看反汇编：

```sh
gcc -x c -std=c11 -O0 -g -Wall -Wextra -Werror -o FIB_C.exe FIB.C
objdump -d -Mintel FIB_C.exe
```

[C 反汇编注释](C_反汇编注释.txt) 保留 GCC 13.4.0 实际生成的三个 C 函数及其注释。C 反汇编为 x86-64，手写汇编为 8086 DOS。

## 递归与寄存器

F(100) 需要 69 位。汇编用 6 个 16 位字保存结果，最低字在前，每个缓存项另有 1 个字标记是否已计算。初始时只有 F(0) 和 F(1) 已就绪；未命中缓存时递归计算 F(n−1) 和 F(n−2)，合并后再标记就绪。每个 n 只计算一次，时间和缓存空间均为 O(n)。

`Fib` 用 `BX=14*n` 传入缓存偏移，用 `DS:SI` 返回结果地址。第一次递归返回的 `SI` 暂存到栈，第二次返回后弹入 `DI`。按低字到高字用 `AX` 和 `ADC` 相加；`INC` 与 `LOOP` 不改进位标志 CF。输出时在副本上用 `DIV` 反复除以 10；每次从高字到低字处理，`DX` 将前一字的余数带到下一字，最后将各轮的十进制余数逆序输出。

## 栈空间与 DEBUG 实测

`.STACK 400h` 分配 1024 字节；LINK 将初始 SS:SP 写入 EXE 头，DOS 加载时初始化。近调用 `CALL` 压入 2 字节返回 IP，随后 `PUSH BP`、`PUSH BX` 各占 2 字节。以新 BP 为基准，`[BP+2]` 是返回 IP，`[BP]` 是旧 BP，`[BP-2]` 是保存的 BX。第二次递归时，本层还压了 2 字节的第一个结果地址。返回时先恢复 BX、BP，再由 `RET` 弹出 IP。

最深有 100 层：首次沿 F(100) → F(99) → … → F(1) 时占 600 字节。F(1) 返回后，F(2) 保存它的结果并调用 F(0)，此时额外占 2 字节，达到 **602 字节**。其余第二次调用均命中缓存，立即返回；它们出现时栈已更浅。十进制输出在递归结束后进行，最多暂存 21 个余数（42 字节），不会与递归峰值叠加。1024 字节为输入输出和中断留有余量。

在 DOSBox 执行 `DEBUG FIB.EXE`，用 `t 2` 初始化 DS，再用 `r bx` 写入 `002A`（3×14）、`r ip` 写入 `0018`（主程序调用 `Fib` 处），直接跟踪递归。以下是本次实测的 SP（十六进制）。“建帧后”已执行 `PUSH BP / MOV BP,SP / PUSH BX`；“返回后”已执行 `POP BX / POP BP / RET`。

```text
执行顺序                 CALL 前  CALL 后  建帧后
main 调用 Fib(3)           0400     03FE    03FA
Fib(3) 调用 Fib(2)         03FA     03F8    03F4
Fib(2) 调用 Fib(1)         03F4     03F2    03EE
Fib(1) 返回到 Fib(2)       SP: 03EE -> 03F0 -> 03F2 -> 03F4
Fib(2) 保存 SI             SP: 03F4 -> 03F2
Fib(2) 调用 Fib(0)         03F2     03F0    03EC
Fib(0) 返回到 Fib(2)       SP: 03EC -> 03EE -> 03F0 -> 03F2
Fib(2) 弹出 DI             SP: 03F2 -> 03F4
Fib(2) 返回到 Fib(3)       SP: 03F4 -> 03F6 -> 03F8 -> 03FA
Fib(3) 保存 SI             SP: 03FA -> 03F8
Fib(3) 调用 Fib(1)         03F8     03F6    03F2
Fib(1) 返回到 Fib(3)       SP: 03F2 -> 03F4 -> 03F6 -> 03F8
Fib(3) 弹出 DI             SP: 03F8 -> 03FA
Fib(3) 返回到 main         SP: 03FA -> 03FC -> 03FE -> 0400
```

可用 `g 0092`、`g 0099` 分别停在两次递归调用前，用 `t` 进入调用、用 `t 3` 走完序言。用 `g 00bd` 停在返回前，再用 `t 3` 观察退出。最后在 `IP=001B` 处执行 `d ds:si l 0c`，读得低字 `0002`，其余五个字为 0。

同样将 BX 改为 `0578`（100×14），设置 IP 后执行 `g 0099`、`t 4`，实测最低 SP 为 `01A6h`：`0400h−01A6h=025Ah`（602 字节）。`d ss:sp l 08` 依次显示保存的 BX、旧 BP、返回 IP、上一层暂存的 SI：`0000 01B0 009C 0091`（按 16 位字解读）。

DOSBox/MASM 5.10 与 Cygwin GCC 版本各验证了 113 组输入：所有 100 个合法 n，以及空行、越界、非法字符和前导零等边界输入。有效结果均与独立的迭代计算一致。
