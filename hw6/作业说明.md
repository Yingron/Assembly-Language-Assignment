# 作业 6　输出日历

从键盘输入 1900～2099 年及 1～12 月，程序按周日到周六的顺序显示月历。空输入、非数字或超范围时，程序会重新提示当前项。

## 运行与编译

- 在 DOSBox 中挂载作业目录，进入该盘后运行 `CALENDAR`。若 MASM 5.10 和 LINK 已加入 DOS 路径，可用 `masm CALENDAR.ASM;` 和 `link CALENDAR.OBJ;` 重新编译。
- 在 Windows 的 Cygwin 环境中运行 `./CAL_C.exe`。编译命令为 `gcc -x c -O0 -g -Wall -Wextra -Werror -std=c11 -o CAL_C.exe CALENDAR.C`。附带的反汇编为 Cygwin x86-64 机器码。

## 星期和月长

1900 年 1 月 1 日为星期一，周日编号为 0。设 `n = year - 1900`。平年有 365 天，对 7 取余为 1，因此每过一年至少增加一格。若 `n > 0`，此前的闰年数为 `(n + 3) / 4 - 1`（整数除法），减去的 1 对应 1900。题目范围内只有 1900 和 2000 两个整百年，其中 2000 是闰年。

将星期一的编号、经过的年数、此前闰年数、本年此前各月天数相加，三月及以后再加上本年的闰日，最后除以 7 取余。二月月长单独按闰年加一。每列占 3 个字符，日期右对齐到 2 字符，周六或月末换行。

## 过程与传参

- **寄存器**　主段将提示串地址放入 DX，`ReadDecimal` 用 AX 返回数值、CF 返回解析状态。日历段的 `MonthInfo` 用 AX、BX 接收年月，再用这两个寄存器返回首日星期和月长。寄存器传参访问直接，但数量有限，调用方需遵守寄存器约定。
- **数据段**　输入缓冲区、月份天数表和月份名偏移表通过 DS 共享。两个代码段读取相同的表和字符串，调用时无需复制。共享的可写缓冲区在下一次输入时会被覆盖。
- **栈**　主段先压年份，再压月份，通过远调用进入 `CALCODE` 中的 `PrintCalendar`。建立栈帧后，`[BP+2]` 是返回 IP，`[BP+4]` 是返回 CS，`[BP+6]` 是月份，`[BP+8]` 是年份。`RETF 4` 恢复 IP、CS，再移除两个字参数。栈可为每次调用保留独立参数，但会增加压栈、寻址和清理开销。

## 跳转和段间调用

- **段内短跳转**　例如汇编清单中 `0059: 74 13`（`JZ LastDay`），把有符号位移 `13h` 加到下一条指令的 IP `005Bh`，到达 `006Eh`。8086 条件跳转只能使用 rel8，范围 −128～127 字节。
- **段内近跳转**　目标超出范围时，可把 `JZ target` 改成反向短跳 `JNZ skip`，紧跟 `JMP NEAR PTR target`，并把 `skip` 放在无条件跳转之后。近跳转的 `E9` 后跟小端 rel16。源码中的 `CALL MonthInfo` 同样使用段内 rel16，操作码为 `E8`，只保存返回 IP。
- **段间远调用**　`CALL PrintCalendar` 使用操作码 `9A`，后跟两字节 IP 和两字节 CS，均按小端排列。目标段地址由 DOS 装载时重定位。远跳转使用 `EA` 和同样的立即数布局，但不压入返回地址。`RETF 4` 的机器码为 `CA 04 00`。

## 验证

使用 MASM 5.10、LINK 3.65 生成 DOS EXE，MASM 报告零警告、零错误。DOSBox 和 Cygwin 两个版本均逐月比对 Python 标准库 `calendar`，覆盖全部 2400 个月的标题、日期、星期列与换行，包括 1900 年二月的 28 天和 2000 年二月的 29 天。两份程序均通过空输入、非数字和超范围后重新输入的测试。
